# STM32 Smart Watch

基于 STM32F103、OLED 显示屏及 MPU6050 传感器的智能手表学习项目。

## 项目简介

本项目为嵌入式学习过程中完成的智能手表系统复现项目，通过对开源项目进行学习、移植和调试，掌握 STM32 外设驱动开发、I2C 通信、OLED 图形界面设计以及 MPU6050 姿态检测等相关知识。

项目实现了时间显示、秒表、菜单交互、水平仪及小游戏等功能。原作者见B站BV1CoGuzEEeN。

## 主要功能

* 时间显示
* 秒表功能
* 多级菜单系统
* MPU6050 姿态检测
* 水平仪功能
* OLED 图形界面显示
* 简单小游戏

## 硬件平台

* STM32F103
* OLED 显示屏
* MPU6050 六轴传感器

## 软件环境

* Keil MDK
* C Language
* STM32 Standard Peripheral Library

## 学习内容

在项目复现过程中主要完成：

* 硬件连接与焊接调试
* OLED 显示驱动调试
* I2C 通信学习与应用
* MPU6050 数据读取与姿态检测
* 菜单系统功能调试
* 项目代码阅读与模块化设计学习
* 工程文件管理与 GitHub 版本管理实践
